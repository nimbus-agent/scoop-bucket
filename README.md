# Nimbus Scoop Bucket

```sh
scoop bucket add nimbus https://github.com/nimbus-agent/scoop-bucket
scoop install nimbus
```

Installs the headless Nimbus gateway + CLI. Update with `scoop update nimbus`.

`bucket/nimbus.json` is generated automatically on each stable Nimbus release — do not edit by hand. See https://github.com/nimbus-agent/Nimbus
